The idea

Data in. Table out.

This repo turns a plain JSON dataset into a table UI by using a declarative pipeline: data is shaped, the UI spec is built, the spec becomes DOM through json-to-tag, and the runtime mounts the final result into the browser.

input data
[{ date: "2026-09-01", amount: 1000 }]
columns + config
Date, Amount, Status
render()
JSON -> spec -> DOM -> table

1. Data

The table begins with plain objects, arrays, and values from an API, file, or Tally export.

2. Config

Columns, labels, totals, actions, and footer rules are described in config instead of hardcoded HTML.

3. Render

The blueprint is compiled and turned into browser DOM, giving us the final table grid.
