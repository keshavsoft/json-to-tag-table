Story Flow Architecture Renderer

How the flow works

1

Input

Business data arrives as plain JSON: rows, objects, values, and metadata.

2

Normalize

Data may be cleaned, transformed, or shaped into a consistent model.

3

Spec

A structure definition and config turn the data into a UI blueprint.

4

DOM

The blueprint becomes actual HTML elements using a JSON-to-DOM engine.

5

Table

The final result is a real table shown in the browser with rows, columns and totals.

→
JSON data
  → normalize / transform
  → UI spec
  → json-to-tag DOM creation
  → browser table
