Repo ecosystem

This repo is part of a larger family of JSON-first UI projects. Each repo has one clear role.

json-to-spec

Compiles a structure and data into a final JSON specification tree.

json-renderers-build

Creates headless component blueprints for tables, selects, and other UI pieces.

json-renderers

Mounts that spec into actual browser DOM and handles runtime rendering.

json-to-tag-table

The table-specific part: columns, rows, state, footer totals, and table behavior.

json-transformer

Transforms and normalizes raw data into the structure expected by the UI layer.

tally-* repos

Fetch and normalize Tally data so business data can flow into the frontend pipeline.
